# Apple Assistive Access：认知无障碍的减法设计

> [!info] 案例类型：✅ 正案例 | 领域：digital | 已核验：2026-10-12

**Apple Assistive Access: Subtractive Design for Cognitive Accessibility**

## 案例概要

iOS 17 引入 Assistive Access：为认知障碍用户提供大按钮、少选项、单任务的极简界面，主屏仅显示精选 App，消息可回表情或自拍视频。

## 结果与影响

被广泛视为认知无障碍的标杆实践；Apple 后续在 iOS/iPadOS 26 开放 Assistive Access scene API 让第三方 App 接入。
