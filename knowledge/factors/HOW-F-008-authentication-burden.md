# 认证与身份负担

## 定义

用户在完成身份认证、账号管理、凭据存储与恢复过程中面临的**认知、感官、运动、时间**等多维负担。核心维度包括：

- **认证方式多样性**：密码、生物识别（指纹/人脸/声纹）、硬件密钥（FIDO2/WebAuthn）、魔法链接、OTP、单点登录（SSO）、第三方联合登录
- **负担类型**：
  - 认知负担：记忆复杂密码、理解安全问题、识别钓鱼
  - 感官负担：验证码识别（视觉/听觉）、人脸识别需光线、指纹需清洁指尖
  - 运动负担：输入长密码、操作硬件密钥、完成手势验证
  - 时间负担：等待短信/邮件、多因子认证流程、账号恢复流程
- **凭据管理负担**：密码管理器兼容性、跨设备同步、备份与恢复、遗产继承
- **排他性风险**：单一认证方式（仅人脸/仅密码/仅短信）对特定能力用户的绝对排除

**与其他因素区分**：
- WHO-F-001/003/009/010：用户能力状态
- WHAT-F-002/003：任务认知负荷/容错性
- 本因素侧重**认证这一特定技术任务**的多通道负担与排他性风险

## 为什么重要

- **密码疲劳**：平均用户管理 100+ 账号，复杂度要求导致重用/写纸条
- **生物识别排他**：指纹磨损/缺失、人脸识别对深色肤色/戴头巾/眼镜用户失效、声纹对喉部手术者失效
- **硬件密钥门槛**：需购买、携带、插拔、防丢失
- **短信/邮件 OTP**：依赖网络/手机号、延迟、SIM 卡劫持风险
- **账号恢复**：安全问题答案可被社工、备用邮箱丢失、人工审核周期长
- **WCAG 2.2 SC 3.3.8 强制要求**：至少提供一条不依赖认知功能测试的认证路径

## 设计响应（替代方案）

必须提供**至少两条独立的、不同能力要求的认证路径**，并允许用户自主选择：

| 认证路径 | 认知 | 视觉 | 听觉 | 运动 | 适用人群 |
|----------|------|------|------|------|----------|
| 密码 + 密码管理器自动填充 | 低 | 低 | 低 | 中 | 多数用户 |
| 生物识别（指纹/人脸） | 无 | 中 | 无 | 低 | 运动受限/认知受限 |
| FIDO2/WebAuthn 硬件密钥 | 低 | 低 | 低 | 中 | 高安全需求/企业用户 |
| 魔法链接/邮件 OTP | 低 | 中 | 无 | 低 | 偶发登录/无设备用户 |
| 短信/语音 OTP | 低 | 无 | 中 | 低 | 无智能手机/视觉障碍 |
| 单点登录（SSO/联合登录） | 低 | 低 | 低 | 低 | 企业/多系统用户 |
| 受信任设备/会话延长 | 无 | 无 | 无 | 无 | 高频用户/认知负荷高 |

**关键原则**：
- 不得强制单一认证方式（WCAG SC 3.3.8 A 级）
- 认证方式间可无缝切换，无需重新注册
- 账号恢复流程不依赖认知测试（如安全问题），改用受信任联系人/设备/硬件密钥
- 密码管理器自动填充必须完美兼容（无 `autocomplete=off` 阻断）

## 跨领域映射

| 领域 | 排除示例 | 包容示例 |
|------|----------|----------|
| 数字产品 | 仅密码登录、验证码无音频选项、禁用密码管理器 | 多因子可选、WebAuthn、魔法链接、会话延长 |
| 工业设计 | 设备配对需复杂 PIN、仅手机 App 控制 | NFC 标签配对、物理按钮确认、Web 控制面板 |
| 建筑设计 | 门禁仅人脸/指纹、访客需前台人工登记 | 多模态门禁（卡/码/生物/远程开锁）、访客临时授权码 |
| 服装设计 | 智能服装仅 App 配对、洗涤后需重新认证 | 物理按钮配对、NFC 标签、无需认证的基础功能 |

## 测量维度

- 认证方式数量（≥2 条独立路径，WCAG 合规）
- 各路径的能力要求标注（认知/视觉/听觉/运动）
- 密码管理器自动填充兼容性（通过/失败）
- 账号恢复成功率与平均耗时
- 因认证失败导致的任务放弃率

## 相关标准与参考

- **WCAG 2.2 SC 3.3.8: Accessible Authentication (Minimum)** — A 级强制
