# 信息密度偏好指标

> 指标 ID：`M-WHICH-F-001-01` · 分类：**用户测试** · 证据等级：**C** · 状态：draft

**英文名**：Information Density Preference Index

关联因素：[[WHICH-F-001-information-density-preference|WHICH-F-001]]（信息密度偏好）

## 定义

用户在多档信息密度设置下的选择频率与满意度评分

## 测量方法

可调节密度档位数 + 用户满意度评分

## 数据来源

- 用户调研
- A/B 测试
- 可用性测试选择行为

## 三档阈值

| 档位 | 阈值 |
|------|------|
| 最低合规 | 提供 2-3 个密度档位可选 |
| 良好 | 提供 4+ 档位或自定义滑块 |
| 优秀 | 自适应推荐 + 完全自定义 + 记忆偏好 |

**单位**：档位数 / 满意度分 (1-5)
