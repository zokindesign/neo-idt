# Cognitive Traits
## Definition

Users' psychological functioning traits in perception, attention, memory, language, problem solving, and decision making — individual differences in processing speed, working memory capacity, attention span, executive function, and language comprehension and expression.

## Why It Matters

The diversity of cognitive ability directly affects how users understand information, learn to operate a product, make decisions, and complete tasks. Ignoring cognitive differences can lead to information overload, confusion, or task failure — most markedly for older adults, children, and people with learning disabilities or neurodivergence. Considering cognitive traits helps design products or services that are easy to understand, simple to operate, and low in cognitive load.

## Subtypes and Specific Dimensions

### Processing Speed
- Simple/choice reaction time, information extraction speed, reading speed, decision latency

### Working Memory and Attention
- Digit/alphanumeric span, sustained attention (CPT), task-switching cost, interference-suppression ability

### Executive Function
- Planning and organization, inhibitory control, cognitive flexibility, maintenance of goal-directed behavior

### Language Comprehension and Expression
- Vocabulary breadth, comprehension of syntactic complexity, metaphor/idiom comprehension, cost of switching between languages

### Numeracy
> Reinforced by the B1 cross-reference pass (INCL-XREF-001, cross-referenced against WCAG COGA requirements)
- Quantity representation (estimation/precise calculation), spatial-numerical reasoning (geometry/chart comprehension), financial literacy (interest/compound interest/risk probability)
- **Related disabilities**: developmental dyscalculia, acquired dyscalculia, math anxiety
- **Design response**: avoid tasks requiring mental arithmetic, provide calculators/automatic calculation, replace numeric comparison with visualization, automatic currency/unit conversion

### Spatial Cognition
- Mental rotation, navigation/route planning, object localization, visuospatial working memory

### Neurodiversity-Related Traits
- ADHD: attention regulation, impulse control, time perception
- Autism spectrum: sensory processing, social cognition, reliance on routine, special interests
- Dyslexia: phonological processing, rapid naming, spelling
- Motor coordination disorders: motor planning, bimanual coordination

## Related Standards and References
- WCAG 2.1: understandability principle (e.g., readability of language, predictability, input assistance)
- ISO 9241-210: human-centred design (considering user abilities)
- Cognitive Load Theory (Sweller et al.)
- Common cognitive assessment instruments: e.g., the Montreal Cognitive Assessment (MoCA), Mini-Mental State Examination (MMSE)
- Guidance from neurodiversity advocacy organizations (e.g., autism associations, ADHD resources)
- Working memory and processing-speed models in educational psychology

## Suggested Quantification Methods
- Processing speed: reaction-time tests (e.g., simple reaction time, choice reaction time)
- Working memory capacity: digit span, alphanumeric span tests
- Attention span: continuous performance test (CPT), task-switching cost
- Executive function: Wisconsin Card Sorting Test, Stroop test
- Language comprehension: vocabulary tests, sentence comprehension accuracy
- Numeracy: numerical comparison tasks, arithmetic fluency tests, number-line estimation tasks
- Subjective load: NASA-TLX, Subjective Workload Assessment Technique (SWAT)
- Data sources: standard procedures for psychological experiments, clinical neuropsychological tests, performance metrics from user usability testing

## Manifestations Across Domains
- **Digital products**: chunked information, step-by-step guidance, fewer menu levels, familiar paradigms, undo and redo, clear error messages that include repair suggestions
- **Industrial design**: simple control interfaces, few operating steps, salient feedback, interlock designs that prevent misoperation
- **Architectural design**: clear signage systems, logical floor numbering, intuitive emergency egress routes
- **Interior design**: furniture whose function is apparent at a glance, switch positions that match habits, reachable storage space
- **Graphic design**: clear information hierarchy, natural visual flow, avoiding information overload, symbol-assisted comprehension
- **Fashion design**: simple dressing and undressing steps, clear size labels, easy to follow care instructions (e.g., using graphic symbols)

## Common Misconceptions and Blind Spots
- Equating "intuitive" with the designer's own familiarity rather than testing with target users
- Over-relying on textual explanations while neglecting the supporting role of graphics or demonstrations
- Ignoring the cumulative effect of cognitive fatigue over long-term use
- Considering only extreme cognitive impairment (e.g., dementia) while ignoring mild or situational increases in cognitive load (e.g., multitasking, high-pressure environments)
- Failing to account for the additional burden of language processing in multilingual or cross-cultural scenarios

## Design Recommendation Keywords
Reduced cognitive load, information layering, consistency, predictability, timely feedback, error tolerance, progressive disclosure, familiar patterns, plain language, visual aids
