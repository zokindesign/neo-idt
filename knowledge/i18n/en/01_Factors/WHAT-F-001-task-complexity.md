## Definition
A composite measure of the number of steps a task requires, the number of decision points, the amount of information, and the skill demands involved.

## Why It Matters
Complexity directly affects:
- Learning cost
- Error probability
- Task abandonment rate
- User satisfaction

## Quantification Criteria
- **Step count**: the minimum number of operations needed to complete a task
- **Decision points**: the number of nodes where the user must make a decision
- **Information volume**: the number of information elements presented simultaneously

## Design Guidelines
- Divide and conquer: break complex tasks into multiple simple subtasks
- Provide task templates and wizards
- Use default values and smart recommendations to reduce the decision burden
- Progressive disclosure: reveal advanced options step by step

## Cross-Domain Manifestations
- **Digital products**: step-by-step wizards, default configurations, smart recommendations
- **Industrial design**: modular design, one-touch operation
- **Architecture**: clear spatial zoning, well-defined functional circulation
- **Fashion design**: simplified dressing steps, multifunctional design

## Related Standards
- Miller's Law: the 7±2 information-chunking principle
- Hick's Law: the more choices there are, the longer the decision takes
