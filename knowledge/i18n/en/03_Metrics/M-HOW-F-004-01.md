# Compatibility Matrix Pass Rate

> Metric ID: `M-HOW-F-004-01` · Category: **Automated testing** · Evidence grade: **C — expert consensus** · Status: draft

Related factor: HOW-F-004 — Compatibility Requirements

## Definition

Automatically regress core flows across the support matrix (browser/OS/AT version combinations)

## Measurement

Automated regression across support matrix × smoke cases; EN 301 549 clause 11 web compatibility check

## Data sources

- CI automated testing
- AT compatibility tools

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | Declared support matrix passes smoke cases 100% |
| Good | Core flows pass with AT combinations (screen reader × browser) |
| Excellent | Backward compatible by 2 major versions with graceful failure degradation |

**Unit**: Matrix pass rate %

## Applicable domains

- digital

## Limitations

AT combination testing is resource-intensive; at the Good tier, cover at least the mainstream combinations (NVDA×Chrome/VoiceOver×Safari).
