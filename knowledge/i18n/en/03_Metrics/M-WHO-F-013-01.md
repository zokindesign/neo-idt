# Anthropometric Fit Percentile

> Metric ID: `M-WHO-F-013-01` · Category: **Manual audit** · Evidence grade: **B — verified research** · Status: draft

Related factor: WHO-F-013 — Body Size & Ergonomics

## Definition

Using ANSUR II and GB/T 10000-2023 anthropometric data, verify the population-percentile coverage of key dimensions (reach/clearance/grip/viewing distance)

## Measurement

Cross-reference key dimensions against population percentiles (first select the dataset by target population: GB/T 10000-2023 for China, ANSUR II as reference for North America)

## Data sources

- Anthropometric datasets
- Physical/drawing measurements

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | Key dimensions cover the target population P5–P95 |
| Good | Coverage P1–P99 |
| Excellent | Key dimensions are continuously adjustable (seat/stand/straps etc.) |

**Unit**: Percentile

## Applicable domains

- industrial
- architecture
- fashion

## Limitations

GB/T 10000-2023 is the latest Chinese-adult anthropometric dataset (replacing the 1988 edition); the two datasets must not be mixed for direct comparison.

## Related standard clauses

- `STD-ANSUR-II`
- `STD-GB-T-10000`
