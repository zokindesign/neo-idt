# Authentication Path Redundancy

> Metric ID: `M-HOW-F-008-01` · Category: **Manual audit** · Evidence grade: **A — mandatory standard clause** · Status: draft

Related factor: HOW-F-008 — Authentication & Identity Burden

## Definition

Audit the authentication path per WCAG 2.2 SC 3.3.8: cognitive-function test exemption, multi-path independence, password-manager compatibility, and recovery flow

## Measurement

Authentication path × capability-requirement matrix audit (cognitive/visual/auditory/motor), item-by-item 3.3.8 check (cognitive test exception/alternative paths/paste allowed)

## Data sources

- Certification-process audit
- AT testing

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | ≥2 independent authentication paths and no mandatory cognitive function test (WCAG 3.3.8 Level AA) |
| Good | Account recovery does not rely on security questions; password-manager autofill is not blocked |
| Excellent | Passwordless paths such as WebAuthn/magic links + session extension + published capability requirements for each path |

**Unit**: Path count / compliant-item pass rate

## Applicable domains

- digital

## Limitations

3.3.8 is a new WCAG 2.2 AA criterion; this project treats it as Level A evidence because it often serves as a mandatory baseline in procurement/regulation.

## Related standard clauses

- `STD-W3C-WCAG22:3.3.8`
