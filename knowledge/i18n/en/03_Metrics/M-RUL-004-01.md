# License & SBOM Completeness

> Metric ID: `M-RUL-004-01` · Category: **Automated testing** · Evidence grade: **B — verified research** · Status: draft

Related factor: RUL-004 — Intellectual Property Compliance

## Definition

Audit license-identification coverage and license conflicts for code/dependencies/assets per the SPDX standard, including the License List short-identifier specification

## Measurement

SCA tool scan (source code + dependencies) → SPDX identifier normalization → copyleft license (GPL family) conflict analysis; asset licensing ledger check

## Data sources

- SBOM scanning
- Asset ledger

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | 100% of components have SPDX license identifiers (no Unknown licenses enter the build) |
| Good | Machine-readable SBOM (SPDX format) + zero copyleft license conflicts |
| Excellent | Complete asset licensing chain (item-by-item licensing proof for fonts/images/audio) + CI monitoring of license changes |

**Unit**: SPDX identification coverage % / conflict count

## Applicable domains

- digital

## Limitations

SPDX covers software and data; hardware IP cores and standard-essential patents (SEP) require separate patent searches — this metric makes no patent-infringement determinations.
