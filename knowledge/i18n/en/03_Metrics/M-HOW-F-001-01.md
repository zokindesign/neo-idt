# Network Resilience Tiers

> Metric ID: `M-HOW-F-001-01` · Category: **Automated testing** · Evidence grade: **C — expert consensus** · Status: draft

Related factor: HOW-F-001 — Network Conditions

## Definition

Automatically test core-function availability and degraded experience across a weak-network/offline gradient

## Measurement

Network-condition throttling simulation (3G/2G/50% packet loss/offline) → automated functional availability probes

## Data sources

- Automated testing
- Real-user monitoring (RUM)

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | Read-only functions available when offline, with a clear offline notice |
| Good | Core tasks completable on weak network (3G level) (timeout ≤ 10s) |
| Excellent | Offline-first architecture with automatic background sync |

**Unit**: Feature retention % / timeout seconds

## Applicable domains

- digital

## Limitations

The 3G reference speed is a consensus value; RUM data must be de-identified.
