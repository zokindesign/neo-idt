# Assistive Technology Compatibility

> Metric ID: `M-WHO-F-001-02` · Category: **Manual audit** · Evidence grade: **A — mandatory standard clause** · Status: draft

Related factor: WHO-F-001 — Physical & Cognitive Ability

## Definition

Check whether interactive components expose name/role/value in a programmatically accessible way and whether state changes are perceivable by assistive technologies (screen readers, switch control) — the foundational safeguard for capability-substitution channels

## Measurement

Traverse core tasks with NVDA/VoiceOver + keyboard-only, recording the announcability of each control's name/role/state; for dynamic feedback check whether it is announced in real time (WCAG 4.1.2/4.1.3)

## Data sources

- Direct screen-reader testing
- Keyboard-traversal records
- Component-list check

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | All controls of core tasks have announcable names and roles (4.1.2) |
| Good | Above minimum, state changes are announced in real time (4.1.3) |
| Excellent | Zero blocking-level issues across the three mainstream screen readers NVDA/JAWS/VoiceOver |

**Unit**: Compliant-control percentage

## Applicable domains

- digital

## Limitations

Screen-reader combination coverage is limited; announcability judgments for complex dynamic regions involve a manual component.

## Related standard clauses

- `STD-W3C-WCAG22:4.1.2`
