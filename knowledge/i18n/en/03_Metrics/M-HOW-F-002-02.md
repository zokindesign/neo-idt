# Task Efficiency on Minimum-Spec Devices

> Metric ID: `M-HOW-F-002-02` · Category: **User testing** · Evidence grade: **B — verified research** · Status: draft

Related factor: HOW-F-002 — Device Capability

## Definition

The efficiency of completing core tasks on minimum-supported-spec devices compared with a baseline device — an application of the ISO 9241-11 efficiency measure (resources expended in achieving goals)

## Measurement

Define minimum supported spec → the same group of users completes core tasks on both the minimum-spec and baseline devices → compare completion time and number of operation steps

## Data sources

- Direct dual-device testing
- Task timing
- Operation logs

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | Low-spec completion time ≤ baseline ×1.5 |
| Good | ≤ baseline ×1.3 |
| Excellent | ≤ baseline ×1.1 and no feature degradation |

**Unit**: Time ratio (low-spec/baseline)

## Applicable domains

- digital

## Limitations

The "minimum supported specification" is defined by the product itself; network conditions must be held fixed during testing.

## Related standard clauses

- `STD-ISO-9241-11`
