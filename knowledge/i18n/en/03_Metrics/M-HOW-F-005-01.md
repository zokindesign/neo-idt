# Legacy Environment Adaptation

> Metric ID: `M-HOW-F-005-01` · Category: **Manual audit** · Evidence grade: **C — expert consensus** · Status: draft

Related factor: HOW-F-005 — Technical Environment

## Definition

Audit adaptation strategies and fallback schemes for target users' existing technology environments (legacy OS / legacy browsers / restricted enterprise environments)

## Measurement

Legacy environment inventory → adaptation/degradation strategy audit → measured degradation experience

## Data sources

- User-environment data
- Degradation testing

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | Explicit support/degradation statements for mainstream legacy environments in the target market |
| Good | Core functions usable in degraded mode (graceful degradation, not a blank screen) |
| Excellent | Automatic distribution of adapted versions based on environment capability |

**Unit**: Environment coverage %

## Applicable domains

- digital

## Limitations

The definition of legacy environments depends on target-market research data.
