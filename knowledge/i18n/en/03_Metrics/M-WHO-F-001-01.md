# Capability Demand Exclusion Rate

> Metric ID: `M-WHO-F-001-01` · Category: **Manual audit** · Evidence grade: **B — verified research** · Status: draft

Related factor: WHO-F-001 — Physical & Cognitive Ability

## Definition

Based on the Cambridge exclusion calculation method (Waller/Langdon/Clarkson 2010), decompose product use into tasks and rate the capability demand of each task, estimating the proportion of excluded users against the population capability distribution

## Measurement

Task analysis → capability demand rating across five categories (vision/hearing/dexterity/reach/mobility) → exclusion rate computed against the 1996/97 DFS capability distribution

## Data sources

- Task analysis
- Expert rating
- Population ability-distribution data

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | Exclusion rate ≤ 10% for any core task |
| Good | Exclusion rate ≤ 5% for core tasks |
| Excellent | ≤ 2% with multiple-disability interaction analysis included |

**Unit**: Excluded-population percentage

## Applicable domains

- universal

## Limitations

Thresholds are project-recommended values and need calibration to the target population; the DFS data describe the 1997 UK population, not China.
