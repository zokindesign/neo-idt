# Low-End Device Performance Floor

> Metric ID: `M-HOW-F-002-01` · Category: **Automated testing** · Evidence grade: **C — expert consensus** · Status: draft

Related factor: HOW-F-002 — Device Capability

## Definition

Automatically measure core-task performance on the minimum-spec device in the target market

## Measurement

Measured on minimum-spec device/emulator: cold start, first screen, core interaction response time (P75/P95)

## Data sources

- Automated testing
- RUM

## Tiers

| Tier | Threshold |
|------|-----------|
| Minimum compliance | Cold start ≤ 5s and core interaction response ≤ 200ms (ISO 9241-112 responsiveness practice) |
| Good | P75 interaction response ≤ 100ms and no crashes on low-memory devices |
| Excellent | Adaptive quality and tiered loading based on device capability |

**Unit**: s / ms

## Applicable domains

- digital

## Limitations

The 200 ms response threshold follows ISO 9241-11 effectiveness-efficiency practice and industry consensus.

- `STD-ISO-9241-110:5.2`
