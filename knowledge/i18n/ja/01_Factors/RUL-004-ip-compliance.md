## 基本定義
製品が使用するすべてのコンテンツ（画像、フォント、音声、動画）と技術（アルゴリズム、ライブラリ、コード、特許）は、適法な許諾を得るかライセンス契約に適合していなければならず、他人の著作権・商標権・特許権の侵害を避ける。

## なぜ重要か
- 侵害訴訟は製品の販売停止、巨額の賠償、評判の低下につながり得る
- オープンソースライセンス（GPL、MIT、Apache）には伝染性の条項があり、全体のリリース方式に影響する
- 企業調達は IP のクリーンさに厳しい要求を課す

## 定量化基準
- **ライセンス一覧**: プロジェクトが依存するすべてのライセンスとその制限
- **コンプライアンス率**: 明確なライセンスまたは許諾のあるリソースの割合
- **特許リスク**: 使用する技術が第三者の特許範囲に含まれるか
- **第三者コンテンツ**: 使用する素材が許諾ライブラリからか、購入済みか

## 設計ガイド
- オープンソース/パブリックドメインのリソースを優先し、ライセンスを遵守する
- コンテンツ審査プロセスを設け、すべての素材に適法な出所を確保する
- IP の出所と許諾の証憑を記録する
- 不確実な IP については法的意見を仰ぐか、差し替える

## 分野横断の現れ
| 分野 | IP 上の検討点 |
|------|--------|
| **ソフトウェア開発** | 第三者ライブラリのライセンス、コード再利用、特許プール |
| **デジタルコンテンツ** | 画像/フォント/音楽の著作権、二次創作の許諾 |
| **ハードウェア製品** | チップの IP コア、通信標準必須特許（SEP） |
| **ブランドデザイン** | 商標の使用、競合要素の引用、パロディの境界 |

## 関連規格
- 各国の著作権法、特許法、商標法
- オープンソースライセンス（GPL、MIT、BSD、Apache）
- 業界標準化団体（IEEE、3GPP）の特許政策
