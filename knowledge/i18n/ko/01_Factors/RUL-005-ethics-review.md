## 기본 정의
제품/서비스가 통과하거나 준수해야 하는 윤리 원칙과 심의 메커니즘으로, 사용자 자율, 사전 동의(informed consent), 데이터 존엄, 공정성, 해악 방지, 설명 가능성 등을 포함하며, 특히 사용자 연구, 데이터 수집, 알고리즘 의사결정과 관련된다.

## 왜 중요한가
- 윤리 위반은 공신력 상실, 사용자 저항, 규제 개입으로 이어진다
- AI 시스템 편향, 다크 패턴, 조작적 설계는 윤리 논쟁을 일으킨다
- 연구 성격의 프로젝트는 기관 윤리위원회(IRB) 심의를 반드시 통과해야 한다

## 정량 기준
- **윤리 체크리스트 완성도**: 모든 윤리 쟁점을 커버하는지
- **사전 동의율**: 사용자가 연구 조항에 동의한 비율(및 이해도)
- **알고리즘 공정성 지표**: 서로 다른 인구 집단의 예측 편향
- **불만과 분쟁**: 윤리와 관련된 사용자 불만 건수

## 설계 가이드
- 초기에 윤리 평가를 도입한다(설계 윤리 워크숍)
- 명확하고 이해하기 쉬운 사전 동의 절차를 제공한다(장황한 조항이 아님)
- 다크 패턴(클릭 유도, 취소 은폐)을 피한다
- 알고리즘의 설명 가능성과 이의 제기 경로를 보장한다
- 윤리 피드백 채널을 설립한다

## 영역별 발현
| 영역 | 윤리 요점 |
|------|----------|
| **사용자 연구** | 사전 동의, 프라이버시 보호, 참가자 권익 |
| **AI 시스템** | 공정, 투명, 책임, 비차별 |
| **소셜 플랫폼** | 사용자 데이터 사용 윤리, 콘텐츠 검수 공정성 |
| **게임 디자인** | 중독 방지 제도, 도박 메커니즘, 중독성 설계 |

## 관련 표준
- Belmont Report: 윤리 원칙(존중, 선행, 정의)
- GDPR: 데이터 보호와 동의
- IEEE Ethically Aligned Design
- 각 기관의 IRB 가이드
