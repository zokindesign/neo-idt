# 보조 사용 맥락

## 정의

사용자가 제품/공간을 사용할 때 **제3자 보조 인력**(돌봄 제공자, 가족 구성원, 전문 요양보호사, 수화 통역사, 번역가, 안내견 등)이 동석하거나 협업하거나 대신 조작하는 상황이다. 핵심 차원은 다음을 포함한다:

- **보조 유형**:
  - 신체 보조(휠체어 추진, 기기 조작 대행, 신체 이동 지원)
  - 감각 보조(수화 통역, 시각 유도, 화면 내용 낭독)
  - 인지 보조(의사결정 지원, 절차 안내, 기억 보조, 감정 진정)
  - 기술 보조(계정 설정 대행, 복잡한 설정 조작 대행, 장애 해결)
- **보조 관계**:
  - 전문 요양보호사/기관 서비스(훈련을 받았고 책임 경계가 있음)
  - 비공식 돌봄 제공자(가족/친구, 감정 관계가 복잡하고 권한이 모호)
  - 지역사회 자원봉사자/동료 지원
  - 보조 동물/지능형 보조 기기

**다른 요인과의 구분**:
- WHO-F-001/003/009: 사용자 자신의 능력 상태
- WHERE-F-007/008: 객관적 환경/공유 상황
- 본 요인은 **제3자가 사용 과정에 능동적으로 개입**하는 것이 가져오는 상호작용 설계 요구(삼방 상호작용: 사용자-보조자-시스템)에 초점을 둔다

## 왜 중요한가

- 화면읽기 프로그램을 돌봄 제공자가 대신 조작할 때 UI는 "방관자 시점"을 지원해야 한다(고대비, 큰 글자, 명확한 상태 안내)
- 스마트 홈을 가족이 대신 설정할 때 "대리 권한 관리"가 필요하다(단계별 권한 부여, 감사 로그)
- 의료기기를 간호사가 대신 조작할 때 "전문 모드/가족 모드" 이중 화면이 필요하다
- 수화 통역사가 화상 회의에 참여할 때 "다중 창 레이아웃"이 필요하다(발표자/통역사/자막 동시 화면)
- 아동/노인 기기를 보호자가 관리할 때 "보호자 대시보드"가 필요하다(사용 시간, 콘텐츠 필터, 위치 추적)

## 설계 대응(both: 대체 수단 + 선택 공간)

### 제약/역량 요소 → 대체 수단 제공
- **대리 조작 화면**: 보조자에게 독립 진입점을 제공한다(웹 관리 백오피스, 모바일 제어 앱)
- **삼방 동기화 뷰**: 주 사용자 화면 + 보조자 화면 상태 동기화(프라이버시를 유출하지 않는 전제하에)
- **권한 단계화**: 읽기 전용/조력 조작/완전 위임/긴급 인수, 사용자는 언제든 철회할 수 있다

### 선호/관계 요소 → 선택 공간 제공
- **자율권 보존 메커니즘**: 사용자는 "완수하지 못할 때만 도움 요청" vs "항상 보조자 주도"를 설정할 수 있다
- **프라이버시 경계 설정**: 보조자가 볼 수 있는 범위를 설정할 수 있다(과제 진행만/전체 내용/이상 경보만)
- **관계 모드 프리셋**: 전문 요양보호사 모드(엄격한 권한/감사)/가족 모드(관대/감정 우선)

## 영역별 매핑

| 영역 | 배제 예시 | 포용 예시 |
|------|----------|----------|
| 디지털 제품 | 대리 권한 없음, 보조자가 계정 비밀번호를 공유해야 함 | 단계별 대리 권한, 보조자 전용 대시보드, 조작 감사 로그 |
| 산업 설계 | 의료기기가 전문 모드만 있어 가족이 보조할 수 없음 | 전문/가족 이중 모드, 물리 키/디지털 권한 병존 |
| 건축 설계 | 동반 공간 없음, 화장실에 동반 공간 없음 | 동반 병상, 동반 화장실, 대기실 동반 구역 |
| 패션 디자인 | 혼자 착탈 불가, 보조 착의가 어려움 | 자석 단추/벨크로, 큰 개구부 설계, 보조 착의 표지 |

## 측정 차원

- 대리 권한 시스템의 단계 완비성
- 삼방 동기화 뷰의 사용성과 지연
- 프라이버시 경계의 설정 가능성
- 보조자 숙달 시간/오류율

## 관련 표준과 참고 자료

- WHO ICF e3 지지와 관계(인간 보조)
- WP-C 연결 예정: IEC 60601 의용 전기 기기 사용성, ISO 21542 건축 접근성(동반 공간)

## B1 교차 대조 설명

본 요인은 INCL-XREF-001 GAP-5 판정으로 신규 추가됨: ICF e3는 "인간 보조"를 명시적으로 나열하며, 나머지 4개 벤치마크에는 이 구조화된 요인이 없다.
