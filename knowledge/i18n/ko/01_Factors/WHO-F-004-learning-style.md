## 기본 정의
사용자가 새 지식을 학습하거나 새 제품을 사용할 때 선호하는 정보 수용과 처리 방식으로, 흔한 유형에는 시각형, 청각형, 읽기·쓰기형, 운동감각형(VAK/VARK 모델)이 있으며 더 깊은 층위의 인지 스타일(장 의존/장 독립, 성찰형/충동형 등)도 있다.

## 왜 중요한가
- 서로 다른 학습 스타일의 사용자는 같은 교육 자료나 안내 절차에 대해 이해 속도와 만족도의 차이가 크다
- 여러 학습 경로를 제공하면 교육 비용과 오류율을 낮출 수 있다
- 학습 스타일 선호를 존중하면 사용자의 자신감과 지속 사용 의지를 높일 수 있다

## 정량화 기준
- **VARK 설문 점수**: 채널별(시각, 청각, 읽기·쓰기, 운동감각) 점수 분포
- **학습 시간**: 모드별 습득에 걸리는 시간
- **검사 성과**: 서로 다른 교육 방식을 사용한 뒤의 이해 검사 점수
- **선호 일치성**: 이러한 모드에 대한 사용자의 명시적 선택과 암묵적 행동의 일치 정도

## 설계 가이드
- 다중 모달리티 콘텐츠(그림·글, 영상, 설명, 상호작용 연습)를 선택 가능하게 제공한다
- 안내 튜토리얼은 필요에 따라 학습 순서를 전환할 수 있게 한다(시연→조작, 또는 조작→힌트)
- 사용자가 기본 도움말 모드(영상/그림·글/상호작용 안내)를 선택할 수 있게 한다
- 반복, 빨리 감기, 느리게 재생 등 속도 제어를 지원한다

## 영역별 발현
| 영역 | 예시 |
|------|------|
| **소프트웨어 사용** | 그림·글 도움말, 영상 튜토리얼, 상호작용 둘러보기, 텍스트 매뉴얼 |
| **기기 조작** | 그림 라벨, 조작 안내 오디오, 실습 지도, 촉각 표식 |
| **공간 안내** | 지도 시각화, 음성 안내, 문자 설명, 실지 체험 |
| **의복 착용** | 영상 코디 튜토리얼, 그림·글 단계, 착용 보조 표식 |

## 관련 표준
- 특정 표준 없음; 교육심리학 연구(예: VARK, Kolb 학습 스타일)
