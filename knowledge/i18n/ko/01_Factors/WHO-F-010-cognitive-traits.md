# 인지 특성 (Cognitive Traits)

## 정의

사용자의 지각, 주의, 기억, 언어, 문제 해결, 의사결정 등 심리 기능 특성으로, 처리 속도, 작업 기억 용량, 주의력 지속 시간, 실행 기능, 언어 이해와 표현 능력 등의 개인차를 포함한다.

## 왜 중요한가

인지 능력의 다양성은 사용자가 정보를 이해하고, 제품 사용을 학습하고, 의사결정을 내리고, 과제를 완수하는 능력에 직접 영향을 미친다. 인지 차이를 무시하면 정보 과부하, 사용 혼란, 과제 실패가 생길 수 있으며 특히 고령자, 어린이, 학습 장애가 있거나 신경다양성 인구에 크게 영향을 미친다. 인지 특성을 고려하면 이해하기 쉽고 조작이 단순하며 인지 부담을 줄이는 제품이나 서비스를 설계하는 데 도움이 된다.

## 하위 유형과 구체적 차원

### 처리 속도
- 단순/선택 반응 시간, 정보 추출 속도, 읽기 속도, 의사결정 지연

### 작업 기억과 주의
- 숫자/문자·숫자 span, 지속적 주의(CPT), 과제 전환 비용, 간섭 억제 능력

### 실행 기능
- 계획과 조직화, 억제 통제, 인지 유연성, 목표 지향 행동 유지

### 언어 이해와 표현
- 어휘 범위, 구문 복잡도 이해, 은유/관용구 이해, 다중 언어 전환 비용

### 수리 인지
> B1 교차 대조 보강(INCL-XREF-001, WCAG COGA 요구 대조)
- 수량 표상(추정/정밀 계산), 공간 수리(기하/도표 이해), 금융 리터러시(이율/복리/위험 확률)
- **관련 장애**: 발달성 계산 장애, 후천성 계산 장애, 수학 불안
- **설계 대응**: 암산을 요구하는 과제 회피, 계산기/자동 계산 제공, 숫자 비교를 시각화로 대체, 통화/단위 자동 환산

### 공간 인지
- 심상 회전, 탐색/경로 계획, 사물 위치 파악, 시각-공간 작업 기억

### 신경다양성 관련 특성
- ADHD: 주의력 조절, 충동 통제, 시간 지각
- 자폐 스펙트럼: 감각 처리, 사회적 인지, 일과 의존, 특수 관심사
- 난독증: 음소 처리, 신속 명칭 회상, 철자
- 발달성 운동 협응 장애: 운동 계획, 양손 협응

## 관련 표준과 참고 자료
- WCAG 2.1: 이해 가능성 원칙(예: 언어 가독성, 예측 가능성, 입력 도움)
- ISO 9241-210: 인간 중심 설계(사용자 능력 고려)
- Sweller 등의 『인지 부하 이론』
- 공용 인지 평가 도구: 예: 몬트리올 인지 평가 척도(MoCA), 간이 정신상태 검사(mini-mental state examination, MMSE)
- 신경다양성 옹호 단체의 가이드라인(예: 자폐 협회, ADHD 자료)
- 교육심리학의 작업 기억과 처리 속도 모델

## 정량화 방법 제안
- 처리 속도: 반응 시간 검사(예: 단순 반응 시간, 선택 반응 시간)
- 작업 기억 용량: 숫자 span, 문자·숫자 순 배열 검사
- 주의력 지속 시간: 지속 주의 검사(CPT), 과제 전환 비용
- 실행 기능: 위스콘신 카드 분류 검사, 스트룹 검사(Stroop test)
- 언어 이해: 어휘 검사, 문장 이해 정확도
- 수리 인지: 숫자 비교 과제, 산술 유창성 검사, 수직선 추정 과제
- 주관 부하: NASA-TLX, 주관 작업 난이도 평가(SWAT)
- 데이터 출처: 심리학 실험 표준 절차, 임상 신경심리학 검사, 사용자 사용성 테스트의 수행 지표

## 영역별 발현
- **디지털 제품**: 정보 분할(chunking), 단계별 안내, 메뉴 위계 축소, 익숙한 패러다임 사용, 실행 취소와 다시 실행 제공, 명확하고 수정 안내가 포함된 오류 메시지
- **산업 설계**: 단순한 제어 인터페이스, 적은 조작 단계, 명확한 피드백, 오조작 방지 인터록 설계
- **건축 설계**: 명확한 표지 시스템, 논리적인 층 번호 매기기, 직관적인 비상 대피 경로
- **실내 설계**: 한눈에 이해되는 가구 기능, 습관에 부합하는 스위치 위치, 도달하기 쉬운 수납 공간
- **그래픽 디자인**: 뚜렷한 정보 위계, 자연스러운 시각 흐름, 정보 과부하 회피, 이해 보조 기호 사용
- **패션 디자인**: 단순한 착용 절차, 명확한 사이즈 표기, 이해하기 쉬운 관리 설명(예: 그래픽 기호 사용)

## 흔한 오해와 맹점
- "직관적"을 목표 사용자 테스트가 아닌 설계자 개인의 익숙함으로 여김
- 문자 설명에 과도하게 의존하고 그래픽이나 시연의 보조 역할을 무시함
- 장시간 사용에서 인지 피로가 누적되는 효과를 무시함
- 극단적 인지 장애(예: 치매)만 고려하고 경미하거나 상황적인 인지 부하 증가(예: 멀티태스킹, 압박 환경)를 무시함
- 다중 언어 또는 문화 간 상황에서 언어 처리의 추가 부담을 고려하지 않음

## 설계 제안 키워드
인지 부하 감소, 정보 분층, 일관성, 예측 가능성, 즉각적 피드백, 오류 관용, 점진적 공개, 익숙한 패턴, 간결한 언어, 시각 보조
