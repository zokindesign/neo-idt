## 정의
사용자가 제품이나 서비스를 사용할 때 개인정보의 유출·추적·오용 및 신체 안전 위협에 대한 우려와 걱정의 정도로, 데이터 프라이버시, 익명성, 괴롭힘 방지, 물리적 안전 등의 측면에 대한 느낌을 포함한다.

## 왜 중요한가
프라이버시와 보안 우려는 사용자가 제품이나 서비스를 사용하고, 신뢰하며, 계속 사용할 의향이 있는지에 직접 영향을 미친다. 기능이 강력하더라도 사용자가 불안하거나 프라이버시 침해를 느끼면 사용을 포기하거나 경쟁 제품으로 옮겨갈 수 있다. 프라이버시와 보안을 고려하면 신뢰할 수 있고 사용자의 자율성을 존중하며 우려를 줄이는 제품이나 서비스를 설계하는 데 도움이 된다.

## 관련 표준과 참고 자료
- GDPR, CCPA, PIPL 등 데이터 프라이버시 법규
- ISO/IEC 27001: 정보 보안 관리
- 프라이버시 바이 디자인(Privacy by Design) 원칙
- 보안 사용성 연구(예: 피싱 공격 방지)
- 각국 사이버 보안법

## 정량화 방법 제안
- 주관적 우려 점수: 척도로 사용자의 프라이버시와 보안에 대한 우려 정도를 측정한다(예: 프라이버시 우려 척도)
- 행동 지표: 최소 필요 정보 제공 여부, 익명 모드 사용, 동의 철회 비율
- 기술 구현: 데이터 암호화 정도, 최소 권한 원칙 준수도, 제3자 프라이버시 인증 통과 여부
- 사건 기록: 프라이버시 민원, 데이터 유출 사건, 보안 취약점 수정 소요 시간
- 데이터 출처: 사용자 조사, 행동 로그, 보안 감사 보고서, 투명성 보고서

## 영역별 발현
- **디지털 제품**: 데이터 최소화 수집, 명확한 프라이버시 정책, 선택적 추적 거부, 종단 간 암호화, 익명 로그인 옵션
- **산업 설계**: 제품에 변조 방지 설계가 있는지, 사용 데이터 수집 여부 및 사용자 고지 방식
- **건축 설계**: 감시 카메라의 명확한 표시와 사용 정책, 출입 통제 시스템의 투명성
- **실내 설계**: 스마트홈 기기의 데이터 사용 설명, 음성 비서의 웨이크 워드 프라이버시 모드
- **그래픽 디자인**: 광고에서 사용자가 추적된다고 느끼지 않게 하는지(예: 과도한 타기팅 광고)
- **패션 디자인**: 스마트 의류의 데이터 수집과 전송 방식이 투명한지, 사용자가 끌 수 있는지

## 흔한 오해와 맹점
- 기능만 좋으면 사용자가 프라이버시를 희생한다고 여긴다
- 법률이 요구할 때만 프라이버시를 고려하고 능동적으로 신뢰를 구축하지 않는다
- 프라이버시 정책이 지나치게 길고 법률 용어로 가득해 사용자가 이해할 수 없다
- 개인화 기능이 필요할 때 충분한 통제 옵션을 제공하지 않는다
- 익명을 기능 없음과 동일시하고, 통제 가능한 공유 정도를 설계하지 않는다

## 설계 제안 키워드
데이터 최소화, 투명성, 사용자 통제, 익명 옵션, 프라이버시 바이 디자인, 신뢰 구축, 프라이버시 대시보드, 동의 관리, 최소 필요 원칙
