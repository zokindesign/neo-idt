## 기본 정의
사용자가 제품에서 사용하는 시간대에 대한 주관적 선호(예: 아침, 심야, 근무 시간대, 주말)로, 실제 사용 가능 시간과 일치하지 않을 수 있다.

## 왜 중요한가
- 사용자 선호에 맞는 시간대 사용은 더 높은 만족도와 효율을 가져온다
- 시간대 선호는 UI 테마(야간 다크 모드), 알림 발송 시점에 영향을 미친다
- 선호를 파악하면 개인화 추천과 사용자 세분화에 도움이 된다

## 정량화 기준
- **시간대 분포 데이터**: 사용자 활성 시간 히트맵
- **자기 보고 선호**: 설문 "언제 사용하는 것을 더 선호하십니까?"
- **시간대 전환 빈도**: 사용자가 고정된 시간대에 사용하는지
- **시간대 만족도**: 시간대별 경험 점수

## 설계 가이드
- 사용자가 "자주 쓰는 사용 시간대"를 설정해 알림과 통지를 최적화하도록 허용한다
- 인터페이스를 자동 조절한다(야간 자동 다크, 아침 밝게)
- 시간대에 따라 다른 콘텐츠나 기능을 추천한다
- 방해 금지 설정을 존중하고 비선호 시간대에 방해하지 않는다

## 영역별 발현
| 영역 | 시간대 적응 |
|------|----------|
| **콘텐츠 플랫폼** | 개인화 푸시 시점, 시간대 전용 콘텐츠 |
| **피트니스 앱** | 훈련 시간 추천, 아침 기상, 수면 유도 명상 |
| **소셜 앱** | 야간 모드, 아침 인사, 취침 전 알림 |
| **스마트홈** | 사용자 습관에 따라 조명, 온도 자동 조절 |

## 관련 표준
- 강제 표준 없음; 행동 분석과 사용자 조사 방법
