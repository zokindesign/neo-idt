## 기본 정의
사용자가 콘텐츠나 기능을 탐색할 때 빠른 개관을 선호하는지, 심층 조사를 선호하는지의 경향.

## 왜 중요한가
- 서로 다른 사용자의 탐색 방식을 충족해 이탈을 줄인다
- 인터페이스 내비게이션 구조 설계(플랫 vs 계층)에 영향을 준다

## 정량화 기준
- **측정 방법**: 사용자 행동 분석(페이지 방문 깊이, 기능 사용률)
- **지표**: 평균 페이지 체류 시간, 기능 사용 다양성
- **선호 세분화**: 일반적으로 '빠른 검색형'과 '심층 조사형'으로 나뉜다

## 설계 가이드
- '빠른 시작' 경로를 제공한다(초보자 기본)
- '고급 설정' 또는 '전문가 모드' 입구를 함께 제공한다
- 내비게이션이 다계층 접근을 지원한다(브레드크럼, 빠른 뒤로가기)
- 검색 기능과 탐색 기능을 함께 중시한다

## 영역별 발현
- **디지털 제품**: 초보자 안내 vs 고급 매뉴얼, 검색의 노출도(prominence)
- **지식 베이스**: 요약판 vs 완전판, 빠른 훑어보기 vs 심층 학습
- **소매 공간**: 선별 진열 vs 상세 탐색 구역
- **의류 선택**: 빠른 코디 추천 vs 상세한 소재·공정 확인

## 관련 표준
- 특정 표준 없음; 사용자 조사 세분화에서 도출
