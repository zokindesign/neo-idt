## 정의
제품이나 서비스 사용이 의존하는 기술 인프라와 기기 조건으로, 네트워크 연결 품질, 기기 성능, 운영체제, 소프트웨어 생태계, 외장 기기 호환성, 기술 업데이트 빈도 등을 포함한다.

## 왜 중요한가
기술 환경의 차이는 제품이나 서비스의 사용성과 성능에 직접 영향을 미친다. 예를 들어 약한 네트워크 환경에서는 온라인 기능을 사용할 수 없을 수 있고, 구형 기기는 새 기능을 지원하지 않을 수 있으며, 필요한 외장 기기가 없으면 상호작용 방식이 제한될 수 있다. 기술 환경을 고려하면 다양한 기술 조건에서도 기본적으로 사용 가능하거나 저하된 경험을 제공하는 제품이나 서비스를 설계하는 데 도움이 되며, 접근성과 내결함성을 높인다.

## 관련 표준과 참고 자료
- WCAG 2.1: 기술 의존성 고려(예: 기술 비의존 대안 제공)
- HTML5와 ARIA 규범의 하위 호환성 지침
- 각국의 광대역 보급률과 네트워크 품질 표준(예: ITU 권고)
- 기기 접근성 기능 가이드(예: Android 접근성 서비스, iOS 접근성)
- 외장 기기 표준: USB, 블루투스, HID(휴먼 인터페이스 장치) 규범 등

## 정량화 방법 제안
- 네트워크 조건: 대역폭(Mbps), 지연(ms), 패킷 손실률, 오프라인 사용 가능 여부
- 기기 성능: CPU 성능, 메모리 크기, 화면 해상도, 입력 방식 지원
- 소프트웨어 호환성: 지원 운영체제 버전, 브라우저 지원 범위, 필요한 플러그인·프레임워크
- 외장 기기 지원: 대체 입력 기기(스위치, 아이 트래커, 음성 제어 등) 지원 여부
- 업그레이드와 유지보수: 자동 업데이트 능력, 장기 지원 주기(LTS)
- 데이터 출처: 네트워크 속도 측정 도구, 기기 실험실 테스트, 시장 점유율 데이터, 사용자 조사

## 영역별 발현
- **디지털 제품**: 오프라인 기능, 저대역폭 모드, 점진적 웹 앱(PWA), 구버전 브라우저 지원, 스크린 리더와 대체 입력 기기 호환
- **산업 설계**: 기기가 공장의 전자기·건조 환경에서 동작하는지, 유선과 무선 두 모드를 지원하는지, 수리에 필요한 도구의 보급 정도
- **건축 설계**: 건축물 내 Wi-Fi 커버리지, 엘리베이터 비상 통신 시스템이 의존하는 네트워크, 스마트 빌딩 시스템의 상호운용성
- **실내 설계**: 스마트 홈 기기의 네트워크 요구, 클라우드에 의존하지 않고 로컬 제어를 지원하는지 여부
- **그래픽 디자인**: 인쇄 파일의 소프트웨어 호환성, 전용 프린터나 후처리 기기가 필요한지 여부
- **패션 디자인**: 스마트 의류의 충전 방식, 데이터 전송이 의존하는 기술(예: NFC, BLE), 휴대폰 앱 연동 지원 여부

## 흔한 오해와 맹점
- 모든 사용자가 고속 네트워크와 최신 기기를 갖추고 있다고 가정함
- 이상적 기술 조건에서의 기능만 고려하고 저하된 경험을 무시함
- 기술 리터러시와 기술 환경의 상호작용을 무시함(예: 고령자는 좋은 기기를 가져도 고급 기능을 쓰지 못할 수 있다)
- 글로벌 제품에서 지역 네트워크 인프라 차이를 고려하지 않음
- 특정 플랫폼이나 생태계에 과도하게 의존함(예: iOS만 또는 Windows만 지원)

## 설계 제안 키워드
저하된 경험, 오프라인 우선, 하위 호환, 다중 플랫폼 지원, 표준 인터페이스, 플러그 가능, 낮은 기술 문턱, 네트워크 적응성, 로컬 우선
