# 작업 지속성 요구사항 (Task Persistence Requirement)

## 기본 정의

작업이 장시간 이어짐(세션 간, 기기 간)을 필요로 하는지, 그리고 데이터 저장·상태 복원의 요구 정도.

## 왜 중요한가

- 사용자는 중단으로 진행 상황을 잃어 좌절과 이탈에 이를 수 있다
- 일부 작업은 원래 완료에 오랜 시간이 필요하다(긴 양식 작성, 콘텐츠 제작 등)
- 지속성 설계는 작업 완료율과 만족도를 높인다

## 정량화 기준

- **작업 평균 완료 시간**: 예상 소요 시간(분/시간/일)
- **중단 빈도**: 사용자가 시간당 중단되는 평균 횟수
- **이어하기 비용**: 작업을 다시 시작하는 데 드는 시간과 인지 부담
- **저장 요구**: 저장해야 하는 데이터의 양과 유형(임시 저장본, 설정, 이력)

## 사적·민감 과제 시나리오
> B1 교차 대조 보강(INCL-XREF-001, WHO ICF d5-d6 자기관리 및 가정생활 대조)

작업 지속성은 사적인 작업에서 특별한 요구를 가진다:
- **화장실/옷 갈아입기/샤워 관련 작업**: 방수, 미끄럼 방지, 청소 용이성, 프라이버시 보호, 신속한 완료
- **의료/복약/모니터링 작업**: 프라이버시, 정확성, 알림, 데이터 기록, 분실 금지
- **금융/법률/신원 인증 작업**: 보안성, 열람 방지, 감사 추적, 되돌리기 가능
- **생리/요실금/장루 관리 작업**: 은폐성, 쉬운 꺼내기, 누출 방지, 거리낌 없음, 신속한 완료
- **정신 건강/상담 작업**: 익명성, 안전한 종료, 데이터 로컬 암호화, 흔적 없음

**설계 시사점**: 사적 작업의 '지속성'은 기술적 저장에 그치지 않고, 프라이버시 경계, 되돌릴 수 있음, 흔적 없는 종료 같은 안전 차원을 포함한다.

## 설계 가이드

- 자동 저장(입력, 진행 상황, 개인화 설정)
- 다중 기기 동기화 지원(클라우드 동기화, 로컬 동기화)
- '지난 작업 이어하기' 입구를 제공한다
- 이전 버전과 롤백 능력
- 중단 지점 재개(대용량 파일 업로드/다운로드)
- **사적 작업 전용**: 익명 모드, 로컬 암호화 저장, 원클릭 흔적 삭제, 긴급 종료 키

## 영역별 발현

| 영역 | 지속성 지원 |
|------|------------|
| **양식 작성** | 자동 임시 저장, 단계별 저장 |
| **게임** | 저장 지점, 클라우드 저장 |
| **콘텐츠 제작** | 임시 저장함, 버전 이력, 멀티 기기 동기화 |
| **학습 플랫폼** | 학습 진도 기록, 이어하기 알림 |
| **의료/금융** | 로컬 암호화, 감사 로그, 되돌리기 가능, 무흔적 모드 |

## 관련 표준

- 통일된 표준 없음; 모범 사례는 시나리오에 의존
- WP-C 연결 대기: ISO 27001 정보 보안(사적 작업 데이터 보호)
