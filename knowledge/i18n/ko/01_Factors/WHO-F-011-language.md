# 언어 (Language)

## 정의

사용자의 모국어, 언어 사용 숙련도, 읽기·쓰기 능력, 특정 언어 변이체(방언, 전문 용어)의 이해 능력. 언어는 정보의 획득, 이해, 표현 방식에 영향을 미친다.

## 왜 중요한가

언어 장벽은 정보 획득과 서비스 이용의 주요 장애물이다. 설계가 특정 언어에만 의존하면 그 언어를 하지 못하거나 숙련도가 낮은 사용자가 배제된다. 언어 요인을 고려하면 다중 언어 지원을 제공하고 이해하기 쉬운 언어를 사용하며 서로 다른 문해 수준을 고려할 수 있어, 정보의 접근성과 서비스의 사용 가능성이 높아진다.

## 하위 유형과 구체적 차원

### 언어 차이(언어학적 층위)
- **모국어와 제2언어 숙련도**: CEFR 등급, 학술/전문 언어 능력
- **방언/지역 변이체**: 어휘 차이, 문법 차이, 어용론적 규칙 차이
- **다중 언어 환경**: 코드 스위칭, 언어 선호 설정, 대체 언어 전략

### 읽기·쓰기 능력(식자 층위)
- **식자 수준**: 문맹, 저식자, 기능적 문맹, 고식자
- **읽기 장애**: 발달성 난독증, 알렉시아(후천성 읽기 장애)
- **쓰기 장애**: 서면 표현 장애, 실행증성 쓰기 장애

### 발화 운동 장애 vs 언어 차이
> B1 교차 대조 보강(INCL-XREF-001, WHO ICF b3과 WCAG 발화 요구 대조)

**핵심 구분**:
| 차원 | 발화 운동 장애(조음/발성) | 언어 차이(언어학/인지) |
|------|--------------------------|------------------------|
| **본질** | 운동 실행 층위의 발음 산출 곤란 | 언어 체계(어휘/문법/어용론)의 차이 또는 장애 |
| **전형적 발현** | 발음 불명료, 발화 속도 이상, 음성 질 이상, 조음 기관 운동 제한 | 어휘 부족, 문법 오류, 이해 곤란, 어용론 부적절 |
| **관련 장애** | 구음장애, 조음 실행증, 후두절제, 성대 마비, 말더듬 | 실어증, 특정 언어 장애(SLI), 제2언어 습득 곤란 |
| **설계 대응** | 음성 입력 대체(텍스트/제스처/안구 움직임), 음성에 의존하지 않는 인증, 음성 합성 출력 | 다중 언어 UI, 쉬운 읽기·쓰기 텍스트, 그래픽 기호 보조, 용어집, 번역 |

**설계 원칙**: 두 유형의 요구를 혼동하지 않는다. 발화 운동 장애 사용자는 언어 능력이 온전하여 대체 입력 채널만 필요할 수 있고, 언어 차이 사용자는 발음이 명료하더라도 언어 층위의 적응이 필요할 수 있다.

## 관련 표준과 참고 자료
- WCAG 2.1: 언어 식별(lang 속성), 이해 가능성 가이드라인(예: 지나치게 복잡한 언어 사용 회피)
- ISO 9241-210: 인간 중심 설계(사용자의 언어와 문화 고려)
- Unicode 표준, BCP 47 언어 태그
- 각국 언어 권리 입법(예: 캐나다 공용어법)
- 쉬운 읽기·쓰기 원칙(Plain Language)

## 정량화 방법 제안
- 언어 커버리지: 지원하는 언어 수, 목표 사용자 모국어 커버 비율
- 가독성 평가: 예: Flesch-Kincaid grade level, Gunning fog index, SMOG 지수
- 번역 품질: 역번역 정확성, 용어 일관성 점수
- 언어 숙련도 평가: 사용자 자가 평가 또는 표준 검사(예: CEFR)
- 데이터 출처: 인구센서스 언어 분포, 이민 당국 언어 서비스 수요, 사용자 조사

## 영역별 발현
- **디지털 제품**: 인터페이스 다중 언어 전환, 콘텐츠 번역, 음성 출력의 다중 언어 지원, 오류 메시지 현지화
- **산업 설계**: 조작 매뉴얼의 다중 언어 제공, 경고 라벨에 그래픽 기호를 사용해 언어 의존 감소
- **건축 설계**: 표지 시스템의 다중 언어, 비상 대피 그래픽 기호, 서비스 안내판 언어 옵션
- **실내 설계**: 가구 사용 설명서의 다중 언어, 스마트 홈 앱의 언어 지원
- **그래픽 디자인**: 인쇄물의 다중 언어 버전, 다중 언어 문자셋 지원 폰트 선택, 그래픽 중심의 정보 위계
- **패션 디자인**: 관리 라벨의 다중 언어, 국제 표준 사이즈표, 세탁·건조 안내의 그래픽화

## 흔한 오해와 맹점
- 영어 또는 하나의 주도 언어로 모든 사용자를 커버할 수 있다고 여김
- 언어 전환만 제공하고 언어 간 문화 차이(예: 날짜 형식, 존대 표현)를 고려하지 않음
- 식자율이 낮거나 읽기 장애가 있는 사용자를 무시하고 문자 정보에 과도하게 의존함
- 기계 번역을 사람 감수 없이 사용하여 오해나 실례를 낳음
- 아이콘이나 색채 사용에서 문화적 의미 차이를 고려하지 않음
- **발화 운동 장애와 언어 차이를 혼동함**: 조음 장애 사용자에게 "표준 발음"을 요구하거나, 비원어민 사용자에게 번역이 아닌 음성 인식을 제공함

## 설계 제안 키워드
다중 언어 지원, 쉬운 읽기·쓰기, 그래픽 기호, 언어 전환, 문화 적합 번역, 우→좌(RTL) 레이아웃, 음성 출력, 용어집
