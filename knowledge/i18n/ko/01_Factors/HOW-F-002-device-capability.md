## 기본 정의
사용자 기기가 연산 능력, 저장 공간, 센서, 배터리 등에서 가지는 하드웨어 제약.

## 왜 중요한가
- 구형 기기나 저사양 기기 사용자가 상당한 비중을 차지한다
- 배터리 지속시간은 사용자의 사용 시간과 시나리오를 제한한다
- 센서 부재는 기능 가용성에 영향을 미친다(예: 자이로스코프가 없으면 일부 게임을 할 수 없다)

## 정량화 기준
- **처리 능력**: CPU 속도, 코어 수, GPU 성능
- **RAM**: 사용 가능한 메모리 크기
- **저장**: 남은 공간
- **센서**: GPS, 카메라, 지문, NFC 등의 구비 여부
- **배터리**: 지속 시간, 충전 조건

## 설계 가이드
- 기기 능력을 감지하여 경량 기능으로 동적으로 조정한다
- 고급 하드웨어가 있어야만 기능이 동작하도록 강제하지 않는다
- "절전 모드" 옵션을 제공한다
- 외부 기기로 대체할 수 있게 한다(예: 외장 키보드)

## 관련 표준
- Progressive Web Apps(PWA) 능력 감지
