## 기본 정의
사용자가 동시에 제시되는 정보량과 세부 수준에 대해 선호하는 정도와 견딜 수 있는 범위.

## 왜 중요한가
- 정보 과부하 → 인지 부하↑, 불안↑
- 정보 부족 → 효율↓, 불신↑
- 시나리오에 따라 요구 차이가 크다(데이터 분석가 vs 일반 사용자)

## 정량화 기준
- **측정 방법**: 시선 추적(응시 시간, 스캔 경로), 사용자 자기 평가(선호 척도)
- **지표**: 화면 요소 밀도, 텍스트 행간 밀도, 데이터 포인트 밀도
- **참고 임계값**: 일반 웹페이지는 글자 크기(Font Size) ≥ 16px, 행간 ≥ 1.5 유지 권장

## 설계 가이드
- '간결 모드'/'상세 모드' 전환 제공
- 정보 계층화: 요약 → 상세(접기/펼치기)
- 사용자가 대시보드를 직접 구성할 수 있게 한다(표시 내용 제어 가능)
- 기본 밀도를 '중간'으로 두고 조정 입구를 제공한다

## 영역별 발현
| 영역 | 저밀도 선호 | 고밀도 선호 |
|------|------------|------------|
| **디지털 제품** | 미니멀 스타일, 넓은 여백, '적음이 곧 많음' | 데이터 밀집, 한눈에 모두 보기, 다중 패널 |
| **산업 설계** | 인터페이스 간소화, 핵심 제어 부각 | 다기능 패널, 파라미터 집중 표시 |
| **건축 설계** | 열린 공간, 간결한 장식 | 다기능 복합, 촘촘한 공간 |
| **패션 디자인** | 간결한 실루엣, 장식 최소화 | 다층 조합, 풍부한 액세서리 |

## 관련 표준
- WCAG 1.4.4: Resize Text(레이아웃에 영향 없음)
- 닐슨 노먼 그룹: 정보 밀도와 가독성의 균형
