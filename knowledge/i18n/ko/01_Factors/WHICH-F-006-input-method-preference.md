## 기본 정의
사용자가 선호하는 시스템과의 상호작용 입력 수단(키보드, 마우스, 터치, 음성, 제스처, 안구 추적, 스위치 기기 등), 그리고 이들 입력 방식 간 선호 강도와 조합.

## 왜 중요한가
- 입력 방식에 대한 사용자의 숙련도, 편안함, 효율은 차이가 크다
- 신체 조건이 일부 입력 방식을 제한할 수 있다(한손 조작, 정밀 제어 등)
- 사용 시나리오도 최적 입력에 영향을 준다(운전 중에는 음성, 사무실에서는 키보드·마우스)
- 입력 전환을 제공하면 접근성과 사용자 만족도가 높아진다

## 정량화 기준
- **입력 방식 사용 빈도**: 각 방식이 작업에서 차지하는 비중
- **전환 빈도**: 같은 세션에서 사용자가 입력 방식을 전환하는 횟수
- **오류율**: 입력 방식별 조작 오류율
- **만족도 점수**: 입력 방식별 편안함과 효율에 대한 점수

## 설계 가이드
- 여러 입력 기기를 동시에 지원하고 단일 방식을 강제하지 않는다(키보드 단축키 유지 등)
- 사용자가 기본 입력법/입력 기기 우선순위를 설정할 수 있게 한다
- 입력 방식 빠른 전환 입구를 제공한다
- 입력 매핑 사용자 정의를 지원한다(키 리매핑, 제스처 사용자 정의 등)
- 환경 인지: 상황에 맞는 입력을 자동 추천한다(이동 중에는 음성 추천 등)

## 영역별 발현
| 영역 | 입력 방식 예시 |
|------|--------------|
| **데스크톱 소프트웨어** | 마우스, 키보드, 터치패드, 펜 입력, 음성 명령 |
| **모바일 앱** | 터치, 제스처, 외장 키보드, 음성 입력 |
| **게임 기기** | 게임패드, 키보드·마우스, 모션 감지, VR 컨트롤러, 핸들 |
| **산업/의료** | 스위치, 풋 스위치, 헤드 컨트롤, 안구 추적, 호흡 제어 |

## 관련 표준
- 플랫폼 접근성 프레임워크(UI Automation, AT-SPI 등)
- 선택적 입력 기기 표준(USB HID 등)
- IEEE 11064: 인간-컴퓨터 상호작용 설계 원칙
