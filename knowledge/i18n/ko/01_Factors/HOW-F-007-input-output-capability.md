## 기본 정의
기기가 지원하는 입력 방식(터치, 버튼, 음성, 게임패드, 시선 추적)과 출력 방식(화면, 스피커, 진동, 점자)의 다양성, 정밀도, 호환성이다.

## 왜 중요한가
- 사용자는 특정 입력 능력(예: 한손 조작, 시각 장애)이 없거나 선호가 다를 수 있다
- 출력 채널이 부족하면 지각 능력이 제한된 일부 사용자가 배제된다
- 환경 요인이 일부 입출력(IO)을 제한할 수 있다(예: 소음 환경에서는 시각 출력 필요)

## 정량 기준
- **입력 채널 수**: 지원하는 입력 방식의 종류(≥3이 바람직)
- **정밀도 요구**: 터치 대상 크기, 키 스트로크, 음성 인식 정확도
- **출력 채널 수**: 지원하는 출력 방식(소리, 시각, 촉각)
- **사용자 정의도**: 사용자가 IO 매핑을 조정할 수 있는지(키 재매핑, 진동 강도)

## 설계 가이드
- 다중 채널 입력과 출력을 지원한다
- 사용자가 일부 채널을 재매핑하거나 비활성화할 수 있게 한다
- 단일 채널 의존을 피한다(예: 순수 터치, 소리뿐인 출력)
- 표준 API를 제공하여 외부 사용자 정의 입력 기기를 연결할 수 있게 한다

## 영역별 발현
| 영역 | IO 예시 |
|------|--------|
| **모바일 앱** | 터치, 음성, 블루투스 키보드, 진동, 화면 낭독 |
| **게임 기기** | 게임패드, 모션 감지, VR 컨트롤러, 레이싱 휠 |
| **산업 제어** | 물리 버튼, 노브, 페달, 표시등, 부저 |
| **웨어러블** | 버튼, 터치패드, 음성, 진동, 소형 화면 |

## 관련 표준
- 플랫폼 접근성 가이드(iOS VoiceOver, Android TalkBack)
- 게임 접근성 표준(Xbox Adaptive Controller)
