## 기본 정의
사용자가 하루나 일주일 중 제품 사용에 할당할 수 있는 총시간과 시간 창(예: 통근, 점심시간, 저녁에만 사용 가능).

## 왜 중요한가
- 사용자의 가용 시간은 과제 길이와 기능 복잡도 상한을 직접 결정한다
- 파편화된 시간에는 과제 분할과 빠른 이어하기 능력이 필요하다
- 시간 가용성 차이는 기능 우선순위와 안내 전략에 영향을 미친다

## 정량화 기준
- **가용 분/일**: 사용자 자기 보고 또는 사용 데이터로 추론
- **시간 파편화 정도**: 가용 시간 블록의 수와 길이(예: 3×15min vs 1×2h)
- **규칙성**: 매일 고정된 시간대에 사용 가능한지
- **시간 충돌 빈도**: 계획된 과제가 다른 일로 중단된 횟수

## 설계 가이드
- 과제 분할과 중단점 이어하기를 지원한다
- "나중에 계속"과 정시 알림을 제공한다
- 일일 목표 시간 설정을 허용한다
- 긴 과제에 예상 완료 시간과 단계별 계획을 제공한다

## 영역별 발현
| 영역 | 시간 적응 |
|------|----------|
| **학습 플랫폼** | 마이크로 강좌, 차시 분할, 학습 계획 |
| **독서 앱** | 장 절 분할, 읽기 진행, 북마크 |
| **온라인 양식** | 자동 임시 저장, 단계별 저장, 이어쓰기 진입점 |
| **프로젝트 관리** | 과제 분해, 시간 추정, 진행 알림 |

## 관련 표준
- 표준 없음; 사용자 조사와 행동 분석 기반
