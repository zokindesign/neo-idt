# 공유 및 공공 사용 맥락

## 정의

사용자가 제품/공간을 독점하는 것이 아니라 **여럿이 공유**하거나 **공개 장면**에서 사용하는 상황이다. 핵심 차원은 다음을 포함한다:

- **동시 공유**: 여러 명이 동시에 사용(가족 TV, 회의실 디스플레이, 공공 셀프 단말기)
- **비동기 공유**: 여러 명이 교대로 사용(가족 태블릿, 사무실 공유 워크스테이션, 도서관 컴퓨터)
- **구경/관찰됨**: 사용 과정이 타인에게 보이거나 들림(공공장소 독서, 지하철 휴대폰, 개방형 사무실 통화)
- **계정/설정 공유**: 가족 공유 계정, 팀 공유 작업 공간, 기기 다중 사용자 로그인

**다른 요인과의 구분**:
- WHERE-F-007(사용 맥락)은 1인 사용의 물리적/사회적 환경에 초점을 둔다
- WHICH-F-008(상호작용 모드 선호)은 사용자의 혼자 vs 협업에 대한 주관적 선호에 초점을 둔다
- 본 요인은 **객관적으로 존재하는 비목표 사용자의 동석**이 프라이버시, 사용성, 안전에 주는 제약에 초점을 둔다

## 왜 중요한가

- 가족 공유 기기: 아동의 오조작 결제, 프라이버시 콘텐츠가 가족에게 노출, 개인화 추천의 상호 간섭
- 공공 셀프 단말기: 비밀번호 입력이 엿보임, 조작 흔적 잔류, 시간 압박(줄 서기)
- 개방형 사무실: 화면 내용 유출, 통화 청취, 회의 방해
- 대중교통/야외: 화면 반사, 소음 방해, 기기 도난 위험

## 설계 대응(both: 대체 수단 + 선택 공간)

### 제약 요소 → 대체 수단 제공
- 프라이버시 모드: 엿보기 방지 필터, 지향성 오디오, 자동 흔적 삭제
- 게스트/임시 모드: 기록을 저장하지 않고, 주 계정 추천을 오염시키지 않는다
- 잠금 화면/빠른 계정 전환: 한 번에 민감 콘텐츠를 숨긴다

### 선호/상황 요소 → 선택 공간 제공
- 공유 기기의 개인화 격리: 다중 사용자 프로필, 지문/얼굴 빠른 전환
- 설정 가능한 "공개도": 업무 자료는 동료에게만, 개인 사진은 가족에게만
- 공공 장면 자동 대응: 공용 Wi-Fi/비컨 감지 시 프라이버시 모드 자동 활성화

## 영역별 매핑

| 영역 | 배제 예시 | 포용 예시 |
|------|----------|----------|
| 디지털 제품 | 가족 공유 계정 추천 혼란, 공공장소 화면 엿보기 | 다중 사용자 프로필, 게스트 모드, 프라이버시 스크린세이버 |
| 산업 설계 | 공유 도구에 사용자 식별 없음, 공공 시설에 프라이버시 설계 없음 | 다중 사용자 RFID 식별, 공공 좌석 분리 |
| 건축 설계 | 개방형 사무실에 프라이버시 구역 없음, 공공 화장실 칸 틈이 큼 | 전화 부스/집중 캡슐, 전(全)성별 화장실, 음향 격벽 |
| 패션 디자인 | 탈의실에 후크 없음/거울 위치 부적절, 공용 탈의실 | 독립 탈의실, 잠금 사물함, 프라이버시 커튼 |

## 측정 차원

- 다중 사용자 프로필 완비성(독립적 데이터 격리를 지원하는지)
- 게스트/프라이버시 모드 가용성
- 엿보기 위험 완화 조치(필터, 지향성 오디오, 자동 삭제)

## 관련 표준과 참고 자료

- UD7 보충 원칙 P8(Community)
- WHO ICF d7(대인 상호작용)과 d9(교육과 일)
- WP-C 연결 예정: ISO 9241-210 사용 상황, 관련 프라이버시 표준
