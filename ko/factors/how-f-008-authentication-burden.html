인증 및 신원 부담

인증 및 신원 부담

2026년 11월 22일7 min read

정의

사용자가 신원 인증, 계정 관리, 자격 증명 저장과 복구 과정에서 직면하는 인지, 감각, 운동, 시간 등 다차원 부담이다. 핵심 차원은 다음을 포함한다:

  • 인증 방식 다양성: 비밀번호, 생체 인식(지문/얼굴/성문), 하드웨어 키(FIDO2/WebAuthn), 매직 링크, OTP, 싱글 사인온(SSO), 제3자 연합 로그인
  • 부담 유형:
    • 인지 부담: 복잡한 비밀번호 암기, 보안 질문 이해, 피싱 식별
    • 감각 부담: CAPTCHA 식별(시각/청각), 얼굴 인식의 조명 요구, 지문 인식의 청결한 손가락 요구
    • 운동 부담: 긴 비밀번호 입력, 하드웨어 키 조작, 제스처 검증 완수
    • 시간 부담: SMS/메일 대기, 다중 요소 인증 절차, 계정 복구 절차
  • 자격 증명 관리 부담: 비밀번호 관리자 호환성, 기기 간 동기화, 백업과 복구, 디지털 유산 상속
  • 배제 위험: 단일 인증 방식(얼굴만/비밀번호만/문자만)은 특정 역량의 사용자를 절대적으로 배제한다

다른 요인과의 구분:

  • WHO-F-001/003/009/010: 사용자 역량 상태
  • WHAT-F-002/003: 과제 인지 부하/내결함성
  • 본 요인은 인증이라는 특정 기술 과제의 다채널 부담과 배제 위험에 초점을 둔다

왜 중요한가

  • 비밀번호 피로: 평균 사용자는 100+ 계정을 관리하며, 복잡도 요구가 재사용/종이 메모로 이어진다
  • 생체 인식 배제: 지문 마모/결손, 얼굴 인식은 어두운 피부색/두건 착용/안경 사용자에게 실패, 성문 인식은 후두 수술자에게 실패
  • 하드웨어 키 문턱: 구매, 휴대, 삽탈, 분실 방지가 필요하다
  • SMS/메일 OTP: 네트워크/전화번호 의존, 지연, SIM 스와핑 위험
  • 계정 복구: 보안 질문 답은 소셜 엔지니어링에 뚫리고, 예비 메일은 분실되며, 수동 검토 주기는 길다
  • WCAG 2.2 SC 3.3.8 강제 요구: 인지 기능 테스트에 의존하지 않는 인증 경로를 최소 한 개 제공해야 한다

설계 대응(대체 수단)

역량 요구가 서로 다른 독립 인증 경로를 최소 두 개 제공하고 사용자가 스스로 선택하게 해야 한다:

인증 경로인지시각청각운동적용 대상
비밀번호 + 비밀번호 관리자 자동 채우기낮음낮음낮음중간다수 사용자
생체 인식(지문/얼굴)없음중간없음낮음운동 제한/인지 제한
FIDO2/WebAuthn 하드웨어 키낮음낮음낮음중간고보안 요구/기업 사용자
매직 링크/메일 OTP낮음중간없음낮음간헐적 로그인/기기 없는 사용자
SMS/음성 OTP낮음없음중간낮음스마트폰 없음/시각 장애
싱글 사인온(SSO/연합 로그인)낮음낮음낮음낮음기업/다중 시스템 사용자
신뢰 기기/세션 연장없음없음없음없음고빈도 사용자/인지 부하 높음

핵심 원칙:

  • 단일 인증 방식을 강제하지 않는다(WCAG SC 3.3.8 A 등급)
  • 인증 방식 간에 재등록 없이 원활하게 전환할 수 있다
  • 계정 복구 절차는 인지 테스트(예: 보안 질문)에 의존하지 않고, 신뢰 연락처/기기/하드웨어 키로 대체한다
  • 비밀번호 관리자 자동 채우기와 완벽하게 호환해야 한다(autocomplete=off 차단 없음)

영역별 매핑

영역배제 예시포용 예시
디지털 제품비밀번호 로그인만 제공, CAPTCHA에 오디오 옵션 없음, 비밀번호 관리자 차단다중 요소 선택, WebAuthn, 매직 링크, 세션 연장
산업 설계기기 페어링에 복잡한 PIN 필요, 모바일 앱으로만 제어NFC 태그 페어링, 물리 버튼 확인, 웹 제어 패널
건축 설계출입이 얼굴/지문만 가능, 방문자는 프런트 수동 등록 필요다중 모달 출입(카드/코드/생체/원격 개방), 방문자 임시 권한 코드
패션 디자인스마트 의복이 앱으로만 페어링, 세탁 후 재인증 필요물리 버튼 페어링, NFC 태그, 인증 없는 기본 기능

측정 차원

  • 인증 방식 수(≥2개 독립 경로, WCAG 규정 준수)
  • 각 경로의 역량 요구 표기(인지/시각/청각/운동)
  • 비밀번호 관리자 자동 채우기 호환성(통과/실패)
  • 계정 복구 성공률과 평균 소요 시간
  • 인증 실패로 인한 과제 포기율

관련 표준과 참고 자료

  • WCAG 2.2 SC 3.3.8: Accessible Authentication (Minimum) — A 등급 강제
  • EN 301 549 9.3.3.8 — EU 조달 표준의 동일 계보 조항
  • NIST SP 800-63B — 인증자 보장 등급(AAL1/2/3)
  • FIDO2 / WebAuthn — 패스워드리스 인증 표준
  • ISO/IEC 29115 실체 인증 보장 프레임워크

B1 교차 대조 설명
